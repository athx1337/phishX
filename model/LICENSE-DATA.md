# Dataset attribution and use

The training data derive from these public research datasets. Raw corpus URLs and HTML are not distributed in this repository. Dataset licenses and upstream requirements remain applicable to dataset copies and derivatives; the repository's code license does not replace them.

- **PhiUSIIL Phishing URL (Website) Dataset**, A. Prasad and S. Chandra, UCI Machine Learning Repository, 2024. [Dataset and attribution](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+website+dataset), [paper](https://doi.org/10.1016/j.cose.2023.103545). Licensed **Creative Commons Attribution 4.0 International**. Changes: extracted URL/label only, mapped original phishing0 to positive1, canonicalized URLs, rejected unsupported/private destinations, removed conflicting labels and duplicates, purged domain overlap, capped domain frequency, trained a new URL-only model. UCI archive SHA256: `0a639fd03aea6308c5b1c10c92aa23c2ce1505447a9137271865cd0badc9a59a`.
- **PhreshPhish v1.0.1**, PhreshPhish dataset contributors, 2025/2026. [Dataset card and authors](https://huggingface.co/datasets/phreshphish/phreshphish), [research paper](https://arxiv.org/abs/2507.10854). Licensed **Creative Commons Attribution 4.0 International**; follow the dataset card's anti-phishing research purpose and ethical-use requirements. Source revision `eca603e0ecd4f698f8d4d226c088659e72681239`, converted Parquet revision `875e5842650e0ec464e911f1cb6d84d14466986a`. Changes: URL/label/date projection of first2 row groups/shard, canonicalization, phishing-label mapping, custom chronological/domain-disjoint partitioning, domain frequency cap, URL-only model training. The official benchmark split and HTML are not used as-is.

[CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/) permits sharing and adaptation with attribution, a license link, and indication of changes. No dataset author endorsement is implied. phishX's intended use here is a free, non-commercial educational anti-phishing scanner. Do not treat model outputs as a verdict about the current operator of a historical URL.

Native and compact model artifacts are newly trained derivatives with the attribution and modifications above. They contain learned tree parameters, not serialized executable Python objects. Exact snapshot hashes and transformations accompany the model in `evaluation.json` and `ml/sources.json`.
